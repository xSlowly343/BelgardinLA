# Гримуар Белгардина

Фанатская памятка по Shadow Raid **Belgardin** (Lost Ark, KR): механики обоих врат в 3D, клипы атак и механик, калькуляторы, награды и Vambrace.

**Сайт:** https://xslowly343.github.io/BelgardinLA/

Автор: **xSlowly** — [Discord](https://discord.com/users/346621596125102083)

## Источники
- Inven: гайды по атакам врат I и II, Time Attack 195, разборы механик
- Arca.live: клипы механик врат II, шпаргалка
- Официальный патчноут Lost Ark: арты, награды, Vambrace
- LOAGG: таблица «Ещё награды» для Hard/Nightmare

Lost Ark и все названия, арты и иконки принадлежат Smilegate RPG; клипы — авторам гайдов Inven и Arca.live. Проект некоммерческий, для личного использования игроками.
